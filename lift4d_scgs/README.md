# lift4d_scgs/ — Stage 3 of Lift4D (4D training)

This directory holds the two-step Lift4D optimization that fuses the per-frame
SAM3D reconstructions into one deformable 4D asset. It is a fork of [SC-GS: Sparse-Controlled Gaussian Splatting](https://github.com/yihua7/SC-GS).

**Setup and usage live in the top-level [`../README.md`](../README.md).**
